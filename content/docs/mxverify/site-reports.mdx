Every valued site has a public report at `https://mxverify.uk/publications/<domain>`. Every report shows the same parts in the same order; its first fold, "How to use this report", applies the guide to that site's own figures.

| Part | What it shows |
|---|---|
| BV score | What one new followed link from the site is worth, the level it is priced at, any caps, and the relevance range. |
| How its links behaved | For audited sites: links placed on the site and checked by bklink audits — still there or removed, followed or nofollow. The only measured figures about placed links. |
| How it links out | From a reading of the homepage and up to ten articles: the share of outbound links marked nofollow, sponsored or ugc. Graded strong, fair or thin. |
| Links to the site | Counts from a third-party backlink index: linking websites, links, nofollow share, linking IP addresses, and the index's spam score of the linking pages. None of these moves BV. |
| Traffic estimate | Modelled monthly traffic from a third-party source, and the top search keywords. An estimate to compare, not a measurement. BV uses only organic search traffic. |
| AI assistant visits | Visits from people who clicked through from an AI assistant's answer. Not a count of citations. |
| Server and network | The address the site serves from and the publications sharing it; network verdicts where footprints of one owner agree. |
| Page speed | Real-user Chrome data over 28 days (Chrome UX Report): LCP, INP, CLS and the Core Web Vitals verdict. |
| Domain and hosting | Registration date, expiry and status from the public registration record; the content category. |
| Similar sites | Up to six sites on the same subject, never ones on the same server or owned alike. Not a recommendation. |

## Using a report to judge a placement

- **Price check.** Take the figure for the level of link on offer and how close the site is to yours. A quote far above the same-topic figure pays for something BV does not measure, such as the site's readers or the vendor's margin.
- **Ask for the level.** An editorial link is level A; a sponsored or guest post is level B at best; any nofollow link is level C.
- **Qualify the site.** Read the level, caps, audited shares, the reading's nofollow share, the server and the spam score together. None of them alone is a verdict.
- **Check the link once it is placed** with a [bklink audit](/bklink/audits). Its results join the site's report.

## Limitations

- BV is a model, not a price, and does not predict what one link will do for one site.
- Traffic, links to the site and AI visits are third-party estimates and can be far off for a small site.
- A reading is a sample of a site, not every page.
- A report is evidence to weigh, not an endorsement of the site or a check of who runs it.
