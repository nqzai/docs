---
title: API keys
description: Make and revoke keys for the BV API from your bklink account.
---

Keys for the [BV API](/api) are made on [bklink.uk/api-keys](https://bklink.uk/api-keys) while signed in.

- **Make a key.** Give it a name (optional) so you can tell keys apart. The key is shown **once**, when it is made: copy it then. Only a fingerprint of it is kept, so it cannot be shown again.
- **Up to 5 live keys** per account. Revoke one to make another.
- **Revoke a key** at any time. Anything using it stops working within about a minute.
- **Partner tier.** The same page has the application for the [partner tier](/api/partner-tier), and, once approved, each day's paid usage and what it was charged.

Keys start with `mxk_` followed by 40 letters and digits. Treat a key like a password; see [Authentication](/api/authentication).
