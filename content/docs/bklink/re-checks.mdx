---
title: Status re-checks
description: Run the live checks again on an existing report to catch links removed or stripped after delivery.
---

A re-check fetches every URL in an existing report again and re-prices the report around what is still live. Each change is dated: a link that was followed at delivery and is now nofollow, removed, or on a dead page shows when it changed.

That dated record is what you show a vendor when you ask for a replacement.

- **Price:** $1.00 per report, whatever its size.
- **When to run one:** after a vendor's guarantee period, before renewing a vendor, or before reporting results to a client.
