---
title: Getting started
description: Create an account, run your first audit and read the result.
---

<Steps>
<Step>

### Create an account

Sign up at [bklink.uk/sign-up](https://bklink.uk/sign-up) with Google or your email. No card is needed. New accounts start with free credit (currently $1.00), enough for one audit of up to 400 links.

</Step>
<Step>

### Name a project

A project is the site you placed links for. The next screen is the upload.

</Step>
<Step>

### Add the placements

Upload what the vendor delivered — a CSV, a spreadsheet or a vendor's PDF report — or scan a domain for the backlinks already pointing at it. Audit each vendor's list as its own campaign, so each vendor gets its own report and verdict. See [Running an audit](/bklink/audits).

</Step>
<Step>

### Confirm the price and run

The exact price is shown before the audit runs and deducted from your wallet when it does. The median audit finishes in about two minutes for roughly 100 links; lists of over a thousand take up to half an hour. The report fills in while it runs.

</Step>
<Step>

### Read and share the report

The report shows each link's state, the servers the publications share, and the value of each placement. Export it as a PDF, send a share link, or build a disavow file from it. See [Reading a report](/bklink/reports).

</Step>
</Steps>

<Callout title="Top-ups">
  When the credit runs out, top up the wallet from $10 by card. There is no subscription, and unspent balance is refundable. See [Wallet and pricing](/bklink/wallet-and-pricing).
</Callout>
