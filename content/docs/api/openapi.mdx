The whole API — endpoints, parameters, result objects, errors and authentication — is described in one OpenAPI 3.1 file:

**[bklink.uk/docs/openapi.json](https://bklink.uk/docs/openapi.json)**

It is checked against the live API's answers when it changes.

## Postman

The collection is in bklink's public Postman workspace: **[postman.com/bklink1/bklink-s-workspace](https://www.postman.com/bklink1/bklink-s-workspace)**.

1. Fork the **mxverify BV API** collection into your own workspace.
2. Make an environment with a variable `bearerToken` (type *secret*) set to your key from [bklink.uk/api-keys](https://bklink.uk/api-keys). The collection sends it as `Authorization: Bearer {{bearerToken}}`; `baseUrl` is already `https://mxverify.uk`.
3. Send **Look up one site**.

To build the collection yourself instead, choose **Import** in Postman and paste `https://bklink.uk/docs/openapi.json`.

## Generate a client

Any OpenAPI 3.1 generator works. For example, TypeScript types:

```bash
npx openapi-typescript https://bklink.uk/docs/openapi.json -o mxverify-bv.d.ts
```

## Versions

The file's `info.version` follows the API: 1.x for `/api/v1`. Changes are listed in the [changelog](/api/changelog).
