Two products, one model of what a backlink is worth.

- **[bklink](/bklink)** audits backlinks you placed or bought. It fetches every linking page live, checks the link is still there and followed, resolves every publication to the server it runs on so networks show up, and values each placement.
- **[mxverify](/mxverify)** is a free backlink value checker. Enter any website and get its **BV score**: the dollar value of one new followed link from it, in a public site report that names the source of every figure.
- **[The BV API](/api)** returns any site's BV score as JSON, so you can show it on your own pages. A key is free.
